# Sécurité

Ce dépôt présente des projets d'automatisation et des exemples pédagogiques. Les scripts peuvent interagir avec des fichiers, des services et des environnements système : il faut les examiner avant exécution.

## Règles de publication

- Aucun mot de passe, token, clé API, cookie ou secret.
- Aucun chemin personnel, nom d'utilisateur local ou adresse privée.
- Aucun fichier de configuration privé ni dump de base de données.
- Aucun script privé du projet J.A.R.V.I.S. ou du serveur Talisman.
- Les exemples doivent utiliser des données de démonstration.

## Exécution prudente

- Lire le code avant de l'exécuter.
- Utiliser un environnement virtuel Python lorsque c'est pertinent.
- Limiter les permissions au strict nécessaire.
- Commencer par les modes de simulation lorsqu'ils existent.
- Sauvegarder les données avant toute opération de modification.
- Ne pas exécuter un script reçu sans en comprendre les effets.

## Signalement

Ne publiez pas de vulnérabilité ou de secret dans une issue publique. Si un problème de sécurité est découvert, contactez le propriétaire du dépôt par un canal privé disponible sur son profil GitHub.
